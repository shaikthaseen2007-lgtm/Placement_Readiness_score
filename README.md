# ReadySet — Placement Readiness Website

A React + FastAPI web application built around the placement-readiness project you uploaded. The original trained model artifacts are retained and loaded by the API.

## Features

- Student registration and login with hashed passwords and signed session tokens
- Student profile form with validation for the 11 original ML input features
- Existing placement probability, company-tier and CTC models integrated into the API
- Five-pillar readiness index and feature importance output
- PDF/TXT resume upload and role-specific ATS-style keyword analysis
- Personalized 90-day roadmap based on the weakest readiness pillar
- Technical diagnostic quiz with answer explanations
- Private per-account assessment history stored in SQLite
- Responsive React dashboard for desktop and mobile
- Readiness radar chart, pillar comparison bar chart, and assessment progress chart
- Larger, more readable typography
- Deployment configuration and public hosting guide (Vercel + Render)

## Requirements

- Python 3.11 or 3.12 recommended (use a Python version supported by the pinned scikit-learn release)
- Node.js 20 or newer and npm
- Internet access for the first dependency installation

## Run locally (Windows)

1. Extract the ZIP to a normal folder, for example `C:\Projects\placement_readiness`.
2. Open a terminal in that folder and create/install the Python environment:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r backend\requirements.txt
```

If PowerShell blocks activation, run `Set-ExecutionPolicy -Scope Process Bypass` in that terminal, then activate again. You can also install packages using `.venv\Scripts\python.exe -m pip install -r backend\requirements.txt` without activating.

3. Start the backend in Terminal 1:

```powershell
cd backend
..\.venv\Scripts\python.exe -m uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

4. Start the frontend in Terminal 2:

```powershell
cd frontend
npm install
npm run dev
```

5. Open **http://localhost:5173**. API documentation is available at **http://127.0.0.1:8000/docs**. Health check: **http://127.0.0.1:8000/api/health**.

## Configuration

Frontend API URL defaults to `http://localhost:8000/api`. To change it, copy `frontend/.env.example` to `frontend/.env` and set `VITE_API_URL` before starting/building the frontend.

For any public deployment, set a long random `APP_SECRET_KEY` environment variable and set `CORS_ORIGINS` to the exact deployed frontend origin(s). Do not expose the development defaults on a public service. The SQLite database is created automatically at `backend/placement_readiness.db` and should be stored on persistent storage.

## Deployment notes

The frontend and backend are separate services. Deploy the frontend as a static Vite site and the backend as a Python ASGI service. Configure `VITE_API_URL` to the public backend API URL at frontend build time, configure backend `CORS_ORIGINS` to the frontend URL, and set `APP_SECRET_KEY`. SQLite is suitable for local/single-instance testing; use PostgreSQL for a production multi-instance deployment and add HTTPS, rate limiting, backup and account recovery before public use.

## Important ML limitations

The three `.joblib` files from the supplied ZIP are used directly; if a prediction fails because of a model/scikit-learn compatibility issue, use the scikit-learn version specified in `backend/requirements.txt`. The supplied dataset was generated by the project's `data_generator.py`; predictions and CTC values are educational estimates, not calibrated employment or salary guarantees. Validate models on representative real placement data before using the outputs for consequential decisions.

## Current scope

This is a runnable full-stack local application starter. It includes working account registration/login, assessment, saved history, resume analysis, roadmap and quiz APIs. It does not include email verification, password reset, OAuth, institution administration, a production PostgreSQL migration, or an automated production deployment pipeline.


## Deploy publicly

See [DEPLOYMENT.md](DEPLOYMENT.md). The included `render.yaml` configures the FastAPI backend on Render and `frontend/vercel.json` configures SPA routing on Vercel. Set `VITE_API_URL` in Vercel to your deployed backend URL ending in `/api`, and set `CORS_ORIGINS` on Render to the exact Vercel origin. A local `localhost` link is not public.
